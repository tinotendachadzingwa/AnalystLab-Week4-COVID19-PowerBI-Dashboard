# AnalystLab-Week4-COVID19-PowerBI-Dashboard
A Power BI dashboard developed during the AnalystLab Africa Data Analytics Internship (Week 4).

### Project Overview

This project analyzes global COVID-19 trends using interactive visualizations and KPIs.

### Tools Used

* Microsoft Power BI
* DAX
* Data Modeling

### Features

* Total confirmed cases, deaths, and recoveries KPIs
* Recovery and death rate calculations
* Global trend analysis
* Country-level analysis
* Interactive filtering

### Dataset

Johns Hopkins COVID-19 Global Time Series Dataset

### Key Skills Demonstrated

* Data visualization
* Dashboard development
* Data modeling
* KPI analysis
* Business storytelling
